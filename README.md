# homebrew-tap

Homebrew formulae for [serpro69](https://github.com/serpro69) projects.

## Install

```bash
brew install serpro69/tap/capy
brew install serpro69/tap/firestore2csv
```

## Formulae

| Formula | Description |
|---------|-------------|
| [capy](https://github.com/serpro69/capy) | Context-aware MCP server for LLM context reduction |
| [firestore2csv](https://github.com/serpro69/firestore2csv) | Export and import Google Cloud Firestore collections as CSV files |

## How it works

Each formula is automatically regenerated by its project's release workflow on every stable release ([capy](https://github.com/serpro69/capy/blob/master/.github/workflows/release.yml), [firestore2csv](https://github.com/serpro69/firestore2csv/blob/master/.github/workflows/release.yml)). Do not edit files under `Formula/` manually.
